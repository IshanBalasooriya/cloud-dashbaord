Three tools, three different kinds of work. Answer three questions to get a pick, or read the panels below and decide for yourself.

Route a task

Think of one real task you have right now, then answer for that task.

1. What do you want to be holding at the end?

2. What does the task have to touch?

The three tools

The shortest version: Claude.ai is a conversation you steer, Claude Code is a collaborator in your repo, Cowork is a delegation you describe once.

Claude.ai

Browser chat

Exploratory thinking, Q&A, drafting, and quick analysis of files you upload. Artifacts render a chart, doc, or small app right in the conversation, and you revise it by asking.

Reach for it when

  • The task is light on context — one file, not a folder tree
  • You want to iterate fast and change direction mid-thought
  • Nothing is installed on the machine you're on
  • The output is something you'll read, copy, or share as a link

Not this one when

  • You'd be uploading files all afternoon
  • Claude needs to run commands or write to your disk
  • You want to walk away and come back to finished work

Your example. Upload a CSV, ask questions about the data, get an interactive chart Artifact you tweak by asking for changes.

Claude Code

Terminal or IDE agent

Real software work. Claude reads the codebase, plans across files, writes and modifies code, runs commands and tests, and corrects itself — with git tracking every change so you can roll back.

Reach for it when

  • The deliverable is code that has to run, not a description of code
  • The task spans files and needs project-wide understanding
  • Writing, running, and debugging belong in one loop
  • You need the file system, terminal, and dev tools

Not this one when

  • The work isn't technical — the setup buys you nothing
  • You'd rather not have a terminal in the picture
  • You just want a quick answer or a one-off snippet

Your example. Point it at a local project, have it read the data files, write the JS, and build an HTML dashboard with Chart.js you can open and iterate on.

Cowork

Claude Desktop app

Agentic work without a terminal. You state an end goal instead of asking a question; Claude works through the folders you share and hands back finished documents, spreadsheets, or decks.

Reach for it when

  • There's a clear deliverable and it touches a spread of files
  • The work is tedious and multi-step — sorting, extracting, summarizing
  • You'd rather describe it once than steer every turn
  • You want it to run on a schedule

Not this one when

  • You're still working out what you want — that's a chat
  • The work lives in a codebase and needs git and a test loop
  • It would need folders you haven't granted access to

Your example. Point it at a messy folder, have it sort files into subfolders, then write a summary document of what it found and did.

Rules of thumb

Conversation or deliverable

Thinking out loud is chat. Wanting a finished file is Cowork or Code.

Uploading files is a smell

Past two or three uploads you've outgrown chat. Move to a tool with local access.

The terminal is the fork between Code and Cowork

Code work needs git and a run-test loop. Document and file work doesn't.

Know your blast radius

Cowork works in a contained workspace limited to the folders you share and asks before consequential actions. Claude Code runs directly in your project with fuller access.

When unsure, start in chat

It's the cheapest place to find out what you actually want. Escalate from there.

  • Chat, Cowork, and Code all live inside the Claude Desktop app as three modes. Cowork and Code exist elsewhere too, but desktop is where they reach your local files.
  • Cowork also runs on web and mobile; local file access is desktop-only. It's on the paid plans, not Free.
